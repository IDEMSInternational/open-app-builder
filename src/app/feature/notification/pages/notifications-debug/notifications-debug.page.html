Notifications

The app has two separate systems for scheduling notifications: campaigns, authored as campaign schedules and rows in data lists, and the notification action (notification: create), authored in template action lists. Each keeps its own records, so this page shows both, alongside everything scheduled on the device.

Tap a list item to log its full details to the console. In a browser, each tab runs its own copy of the app, so this page only shows notifications scheduled in the same tab.
